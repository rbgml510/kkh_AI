개인 일정 알람 개인정보처리방침

시행일: 2026-11-12

1. 다루는 정보

  • 일정: 사용자가 직접 입력한 제목, 날짜, 시간, 길이, 장소, 메모, 알람 여부. 앱이 만든 전용 캘린더의 일정을 읽고 쓰며 화면에 보여 줍니다.
  • 캘린더 목록 정보: 캘린더 이름, ID, 사용자의 권한. 다른 PC 에서 이미 만들어 둔 전용 캘린더를 찾는 데에만 쓰며, PC 에는 찾은 전용 캘린더의 ID 하나만 저장합니다. 다른 캘린더의 일정 내용은 읽지 않습니다.

이름, 이메일 주소, 연락처 등 계정 정보는 수집하지 않습니다.

2. 정보의 이용

위 정보는 일정을 전용 캘린더에 저장하고 앱 화면에 월 단위로 보여 주는 데에만 사용합니다. 광고, 분석, 판매에 쓰지 않습니다.

3. 저장과 전송

  • Google 로그인 정보(토큰)와 전용 캘린더 ID 는 사용자 PC 에만 저장되며, 로그인 정보는 운영체제 암호화로 보호됩니다.
  • 앱은 일정을 Google 에만 보냅니다. 개발자나 다른 제3자의 서버로 보내지 않습니다.
  • 사용자가 AI 도우미(예: Claude Code)에게 일정 등록을 맡기는 기능을 쓰면, 사용자가 말한 일정 내용과 등록 결과(제목, 일시, 장소)가 그 AI 서비스로 전달됩니다. 이 전달은 사용자가 고른 AI 서비스의 개인정보처리방침을 따릅니다.

4. 삭제

  • 앱의 캘린더 설정에서 '연결 끊기' 또는 '설정 모두 지우기'를 누르면 PC 에 저장된 로그인 정보가 삭제되고, 앱이 Google 에 권한 해제를 요청합니다. 네트워크 상태 등에 따라 이 요청이 실패할 수 있으므로, Google 계정의 '타사 앱 및 서비스' 화면에서 권한이 해제되었는지 확인하고 직접 해제할 수 있습니다.
  • 캘린더의 일정은 Google 캘린더에서 직접 지울 수 있습니다.

5. Google API 데이터 사용

Google API 에서 받은 정보의 사용과 다른 앱으로의 전송은 Google API 서비스 사용자 데이터 정책의 제한적 사용(Limited Use) 요구사항을 따릅니다.
