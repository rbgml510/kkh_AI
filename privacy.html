Hamster Desk 개인정보처리방침

시행일: 2026-11-12

1. 수집하는 정보

Hamster Desk 는 사용자가 직접 입력한 일정(제목, 날짜, 시간, 길이, 장소, 메모, 알람 여부)만 다룹니다. 이름, 이메일 주소, 연락처 등 계정 정보는 수집하지 않습니다.

2. 정보의 이용

입력한 일정은 사용자 본인의 Google 캘린더 중 이 앱이 만든 'Hamster 알람' 캘린더에 저장하고, 앱 화면에 월 단위로 보여 주는 데에만 사용합니다. 다른 캘린더의 일정은 읽거나 쓰지 않습니다.

3. 저장과 전송

Google 로그인 정보(토큰)는 사용자 PC 에만 운영체제 암호화로 저장됩니다. 일정과 로그인 정보를 개발자나 제3자의 서버로 보내지 않으며, 광고·분석·판매에 쓰지 않습니다. 앱이 통신하는 곳은 Google 뿐입니다.

4. 삭제

앱의 캘린더 설정에서 '연결 끊기' 또는 '설정 모두 지우기'를 누르면 PC 에 저장된 로그인 정보가 삭제되고 Google 에서도 권한이 해제됩니다. 권한은 Google 계정의 '타사 앱 및 서비스' 화면에서도 언제든 해제할 수 있습니다. 캘린더의 일정은 Google 캘린더에서 직접 지울 수 있습니다.

5. Google API 데이터 사용

Google API 에서 받은 정보의 사용과 다른 앱으로의 전송은 Google API 서비스 사용자 데이터 정책의 제한적 사용(Limited Use) 요구사항을 따릅니다.
